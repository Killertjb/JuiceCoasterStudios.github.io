# Media: Ploeter Printing

Everything visual for this service lives here. Paths in the JSON files start with `media/`.

| Folder | What goes in it | Format |
|--------|-----------------|--------|
| `gallery/` | Photos of finished work, listed in `gallery.json` | JPG or WebP, about 1600 px wide, under 400 KB each |
| `photos/` | Hero / background image, team and studio photos, share image | JPG or WebP, up to 1920 px wide, under 400 KB each |
| `videos/` | Short clips only. GitHub rejects files over 100 MB, so put longer videos on YouTube | MP4 |
| `branding/` | Logos, colour and font notes | SVG or PNG |
| `press/` | Brochures, price lists, one-sheets | PDF |

## House rules
- File names are **lowercase, with hyphens, no spaces**: `business-cards-01.jpg`. GitHub Pages is case-sensitive.
- Shrink images before uploading. Large photos make the page slow for visitors on mobile data.
- Only upload media you own or have permission to use.
