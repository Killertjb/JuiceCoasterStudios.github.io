# Media: NHS

Everything visual or audible for this artist lives here. Paths in the JSON files start with `media/`.

| Folder | What goes in it | Format |
|--------|-----------------|--------|
| `covers/` | One cover image per release, named after the release `id` in `releases.json` (e.g. `midnight-dreams.jpg`) | Square JPG, PNG or WebP, about 1400 x 1400 px, under 500 KB |
| `photos/` | Hero / background image, portraits, press photos, share image | JPG or WebP, up to 1920 px wide, under 400 KB each |
| `videos/` | Short clips only. GitHub rejects files over 100 MB, so put full videos on YouTube and use `youtubeId` in `videos.json` | MP4 |
| `branding/` | Logos, colour and font notes | SVG or PNG |
| `press/` | Press kit, one-sheet, stage plot / rider | PDF |

## House rules
- File names are **lowercase, with hyphens, no spaces**: `summer-praise-party.jpg`. GitHub Pages is case-sensitive.
- Shrink images before uploading. Large photos make the page slow for visitors on mobile data.
- Only upload media you own or have permission to use.
