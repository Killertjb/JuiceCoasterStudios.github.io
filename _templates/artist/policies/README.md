# Policies: {{NAME}}

Terms and policies that belong to **{{NAME}}**: the documents a visitor, client or promoter may need to read.

## How it works
1. Save each document in this folder (for example `booking-terms.pdf`).
2. List it in `policies.json` with a title and a one-line summary.
3. It then appears under **Policies & Terms** on the page. If the list is empty the section is hidden.

## Tips
- Use **PDF** or **HTML** for anything visitors should open. A `.md` file is fine for your own notes but browsers show it as plain text.
- Keep file names lowercase with hyphens: `refund-policy.pdf`.
- This repository is public, so only add documents you are happy for anyone to read.

## Ideas for what to put here
- Booking terms (deposit, cancellation, travel and accommodation)
- Licensing and usage (sync, sampling, remixes, use of music in videos)
- Technical rider / stage plot
- Privacy notice, if you collect emails or mailing-list sign-ups
